## Folder Structure

```
Patterns/
  1.js ... 20.js     pattern printing problems, numbered in order
  number-pattern.js  extra number pattern
```

Each file prints one pattern using nested loops, for example stars, numbers, letters, and the number crown pattern.

## How I Practise

1. Watch the topic video and understand the idea
2. Try the problem on my own first
3. Write and test the solution
4. Commit and push to GitHub

## How to Run a File

```bash
node Patterns/1.js
```

You need Node.js installed.

## Example

```
Pattern: Right-angled triangle
Approach: Outer loop for rows, inner loop for the stars in each row
```
